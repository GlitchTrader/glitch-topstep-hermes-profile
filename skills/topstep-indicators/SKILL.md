# Indicator analysis

Use only fields present in the sealed envelope. Analyze RSI, MACD, ATR, and indicator or price divergences with their available timeframe and freshness. Treat indicators as evidence, never as automatic entry triggers. If the required values or comparison windows are absent, stale, or inconsistent, return `missing_required_evidence` or `no_edge`; do not infer or invent indicator readings. This skill has no execution authority and never creates or submits intents.
