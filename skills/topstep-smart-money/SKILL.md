# Smart-money analysis

Use only fields present in the sealed envelope. Analyze fair-value gaps (FVGs), displacement, order blocks, liquidity pools, liquidity sweeps, and acceptance or rejection around structural liquidity. State the exact evidence and timeframe for every claimed feature. A pattern name is not directional proof: if the required bars, levels, or order-flow evidence are absent, stale, or inconsistent, return `missing_required_evidence` or `no_edge`. This skill has no execution authority and never creates or submits intents.
