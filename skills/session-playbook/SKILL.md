# Session Playbook

Use `decision_packet.session` and `stream_health` when present. Session context informs confidence; it never alone forces `NOTHING` or blocks risk-reducing `EXIT`.

1. Distinguish regular, maintenance, asia, and unknown phases with their authority labels.
2. Maintenance and thin liquidity reduce participation confidence; they do not auto-flatten.
3. Respect `entry_window_open` and operator schedule fields as **context**, not hidden strategy gates.
4. Name open, lunch, and close **as narrative anchors** only when packet session fields support them.

Pass session context to thesis: phase, stream health, schedule boundaries, and what is unknown.
