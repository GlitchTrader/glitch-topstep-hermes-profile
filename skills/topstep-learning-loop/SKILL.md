# Learning Loop

1. Debrief each new canonical learning-eligible completed outcome exactly once.
2. Run hourly supervision only when new episodes exist.
3. Replace the current five-hour plan only when new hourly reviews exist.
4. Run the daily journal only after the trading session and only when attributable episodes exist.
5. Retrieve durable memory once per loop. Only the daily loop may write memory, and only from repeated attributable evidence.
6. Cognitive candidates remain proposed unless the deterministic worker confirms the operator-enabled activation policy and evidence threshold.
7. Every model call is isolated and receives bounded evidence. No learning loop may submit an intent, access the gateway, or modify execution policy.
