# Hermes cycle prompt layout (GTHP-DATA-01-C)

Four labeled blocks in `CYCLE_OPERATOR_INSTRUCTION` / cycle prompts:

1. **MANDATORY COGNITION** — operator role, symmetric flat/positioned evaluation, rebuild hypotheses each cycle.
2. **EVIDENCE RULES** — packet vs frames, alignment lag, session levels, depth geometry, multi-instrument ranking.
3. **ACTION CONTRACT** — supported_actions only, v3 intent fields, protection_status while positioned.
4. **OUTPUT CONTRACT** — strict JSON, decision_audit fields, wake_triggers semantics.

Gateway schema is unchanged; this document is the review anchor for prompt refactors.
